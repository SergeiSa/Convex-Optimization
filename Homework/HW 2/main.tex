\section*{Домашняя работа 2 }

Разработайте планировщик траектории для квадрокоптера в переменных: положение $p$, скорость $v$, ускорение $a$ и рывок $j$ (все - для центра масс робота в абсолютной системе координат) пользуясь свойством дифференциальной плоскостности (differential flatness). Задайте для планировщика начальное и конечное положение и ориентацию робота. Потребуйте нулевую начальную и конечную скорость. Также:

\begin{itemize}
    \item По полученной траектории восстановите ориентации робота. Выведите на экран набор порожений робота. Число промежуточных точек $M = 10+N$, где $N$ - номер студента по списку.

    \item Покажите как меняется число переменных и временные затраты на вычисления при увеличении числа промежуточных в 2 раза и в 10 раз.
    
    \item  (Дополнительно) Постройте последовательность положений и ориентаций робота отрисовав робот (упрощенно) в каждой точке.

\end{itemize}
